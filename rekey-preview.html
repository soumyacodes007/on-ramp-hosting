Rekey with Pera

This standalone browser preview tests the Pera wallet flow outside Claude. It builds the rekey transaction in-browser, opens the Pera pairing flow, and broadcasts the signed transaction to Algorand.

Best tested from a local web server or deployed URL, not a raw file:// tab. WalletConnect and mobile deep linking are much more reliable in a normal browser origin.
Preview rule: use Algorand Testnet only for delegated-session testing. This page can generate a session signer that spends from the rekeyed account without your original private key. Save the session mnemonic shown below before approving the rekey.
